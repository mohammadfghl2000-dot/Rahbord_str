# راهبرد شوشتر
سامانه فارسی مدیریت کاربران، حوزه‌ها و گزارش‌های فعالیت با Supabase.

## راه‌اندازی
- فایل app.js از Supabase URL و کلید publishable استفاده می‌کند؛ این کلید عمومی است و دسترسی داده‌ها باید فقط از طریق RLS کنترل شود.
- ثبت‌نام عمومی در این نسخه فعال نیست؛ حساب‌ها باید توسط مدیر از Supabase Auth ایجاد و سپس نقش/حوزه آن‌ها در profiles و user_area_access تنظیم شود.
- حساب تازه‌ساخته‌شده به‌صورت پیش‌فرض غیرفعال و با نقش area_force ایجاد می‌شود.
- برای انتشار، پوشه ریشه را در Netlify با publish directory برابر . منتشر کنید.
